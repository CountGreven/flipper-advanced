# Flipper Advanced, distribution site

Public distribution point for **Flipper Advanced**, a full-colour ESP32-S3 Flipper
firmware for the LilyGo T-Embed CC1101 (built on Sor3nt's Flipper-Zero-ESP32-Port
and the upstream Flipper Zero firmware).

- **Web flasher:** https://countgreven.github.io/flipper-advanced/
- `manifest.json` + `firmware/` — ESP Web Tools flashable image set (bootloader, partition table, app, ota-data).
- `version.txt` — latest version string, consumed by the device's over-the-air updater.
