Flipper Advanced

Full-colour ESP32-S3 Flipper firmware for the LilyGo T-Embed CC1101. Flash it straight from your browser.

Your browser can't flash over USB. Use desktop Chrome or Edge. USB access was blocked. Reload and allow the serial port.

Version 2.0.0 · ESP32-S3 · 16 MB flash

Chrome / Edge desktop WebSerial No install
How to flash
  1. Connect the T-Embed to this computer with a USB-C cable.
  2. Click Flash Flipper Advanced and pick the device's serial port (ESP32-S3 / USB-Serial-JTAG).
  3. Let it write and verify, then the device reboots into the new firmware.

Already running Flipper Advanced? You can also update over WiFi from Settings → WiFi → Web-Filesystem / Update, no cable needed.

Open source

Flipper Advanced is GPLv3, built on Sor3nt's Flipper-Zero-ESP32-Port and the upstream Flipper Zero firmware. The source repository is being prepared for public release; corresponding source is available on request in the meantime.
